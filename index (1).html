The Associative Network Memory Model

Brand knowledge lives in memory as a network of linked nodes. Build a brand's network below by linking associations, setting how strong each link is and whether it's favorable, then run activation to see which associations surface first — and which barely register at all.

Click a node to link it to the brand. Once linked, use the controls beneath it to cycle strength (weak / medium / strong) and toggle favorability (+ / −). Then run activation.
